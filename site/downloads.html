Install

Windows: run the installer. bloop isn't code-signed yet, so SmartScreen may say "unknown publisher": choose More info → Run anyway. When it finishes, Launch bloop opens setup.

Linux: make the AppImage executable and run it. Keep it in a folder you can write to (for example ~/Applications) so it can update itself. On first run it adds itself to your app menu.

chmod +x bloop-*-x86_64.AppImage
./bloop-*-x86_64.AppImage
  • Saved API keys and the ChatGPT sign-in go in your keyring (GNOME Keyring, KWallet or KeePassXC).
  • GNOME shows the tray icon with the AppIndicator extension (Ubuntu includes it).
  • Hyprland, Sway and i3 need one config line to float the notch; bloop shows it with a Copy button.

Check a download

Each file has a .sha256 file next to it. Compare them before you run it:

# Windows (PowerShell): the hash must match the .sha256 file
Get-FileHash .\bloop-setup-<version>.exe

# Linux: download both files into one folder, then
sha256sum -c bloop-<version>-x86_64.AppImage.sha256

bloop's own updater does the same check before it installs anything. More in the code signing policy.
