The notch up top is real. Rest your mouse on it.

Your AI, tucked into the top of your screen.

bloop is a tiny chat notch for Windows and Linux. It rests as a thin sliver at the top of your screen, pops open when you need it, and talks to your model: Ollama, llama.cpp, Unsloth Studio, ChatGPT, Claude Code or Codex.

How it works

Out of the way until you want it.

The notch is just for chatting. It grows with the same spring motion you feel in the hero, then tucks itself away again.

  1. 1Rest your mouse on the sliver

    A 120-pixel sliver hugs the top of your screen. Hover it and it pops into a pill; move away and it shrinks back.

  2. 2Click to chat

    The pill opens into a panel. Replies stream in as they're written, with highlighted code and real math formulas, while Bloop thinks, talks and cheers along.

  3. CtrlAltB

    3Press Ctrl+Alt+B from anywhere

    A global shortcut opens and closes it from any app. It also hides itself during fullscreen apps and presentations.

Bring your own model

Your model, your machine.

bloop doesn't ship a model or phone home. Point it at what you already run.

  • Ollama

    Any installed model, streamed from 127.0.0.1:11434. Default qwen3:4b.

  • llama.cpp

    The llama.cpp server or any OpenAI-compatible endpoint, local or remote.

  • Unsloth Studio

    Chat with the models you fine-tune, on 127.0.0.1:8888.

  • ChatGPT

    Sign in with ChatGPT and chat on your plan. The session is encrypted for your Windows account.

  • Claude Code

    Uses the CLI you're already signed in to, in chat-only mode.

  • Codex

    Same for the Codex CLI, streamed as it's written.

  • Anything OpenAI-compatible

    LM Studio, vLLM, a server down the hall. If it speaks /chat/completions, bloop can talk to it.

  • Local-first: nothing is downloaded or started for you.
  • API keys live in Windows Credential Manager, never in a file.
  • CLIs run chat-only: no tools, no file access.

Private by design

Your chats stay on your computer.

  • Stored locally

    Conversations live in a SQLite file in your own data folder. Nothing syncs anywhere.

  • No tracking

    No accounts, analytics or telemetry, in the app or on this page.

  • Checked updates

    Updates come from GitHub Releases and are verified against a SHA-256 checksum before they install.

Questions

Frequently asked questions

What is bloop?

bloop is a free, open-source AI chat app for Windows that lives in a small notch at the top of your screen. It rests as a thin sliver, pops open when you hover or press Ctrl+Alt+B, and chats with a model you choose.

Is bloop free?

Yes. bloop is free and open source under the MIT licence. It has no accounts, subscriptions or paid tiers.

Which AI models does bloop work with?

Ollama, the llama.cpp server, Unsloth Studio, any server with an OpenAI-compatible /chat/completions endpoint (such as LM Studio or vLLM), your ChatGPT plan through Sign in with ChatGPT, and the Claude Code and Codex command-line tools you are already signed in to. bloop does not include a model.

Does bloop work offline?

Yes, with a local model such as Ollama, llama.cpp or Unsloth Studio running on your computer. ChatGPT, Claude Code and Codex need an internet connection, because they run in the cloud.

Can bloop show code and math?

Yes. Replies stream in as they are written and are formatted as Markdown: code blocks are syntax-highlighted with a Copy button, and LaTeX formulas such as fractions, roots, sums and matrices are drawn as real math.

Where are my chats stored?

On your computer, in a SQLite file in your own data folder. bloop has no accounts, analytics or telemetry, and API keys are kept in Windows Credential Manager. Your messages only go to the model you configured.

Can bloop run commands or change files on my computer?

No. bloop is chat-only. The Claude Code and Codex CLIs run with their tools switched off and in a read-only sandbox, and bloop stops a reply if either tries to use a tool.

Does bloop work on macOS or Linux?

Linux, yes: from version 0.6.0 there is an x86_64 AppImage for GNOME, KDE Plasma, Xfce, Hyprland, Sway and other desktops (glibc 2.35 or newer, a Vulkan or OpenGL driver). On Windows, bloop runs on Windows 10 and 11 with a DirectX 12 graphics driver. macOS isn't supported.

Why does Windows say "unknown publisher" when I install bloop?

The installer is not code-signed yet, so Windows SmartScreen warns about it. Choose More info, then Run anyway. Updates are checked against a SHA-256 checksum before they install.
