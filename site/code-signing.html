bloop

Code signing policy

Status: bloop has applied for free code signing from SignPath Foundation. Until that is approved, releases (up to and including 0.4.0) are not code-signed, and Windows SmartScreen may say "unknown publisher". Each release still ships with a SHA-256 checksum that bloop's updater checks before installing.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

  • bloop.exe and the installer bloop-setup-<version>.exe, for each release published on GitHub Releases.
  • Both are built by GitHub Actions from a version tag of the public repository LaurentMaxhuni/bloop. Nothing built on a personal computer is signed.
  • The uninstaller that Inno Setup writes during installation is not signed.
  • The Linux AppImage bloop-<version>-x86_64.AppImage (from 0.6.0) is built by the same workflow from the same tag. It is not signed; check it against its .sha256 file.
  • bloop is open source under the MIT licence, and so are all the components built into it.

Team roles

  • Committers and reviewers: LaurentMaxhuni. Changes from anyone else arrive as pull requests and are reviewed before they are merged.
  • Approvers: LaurentMaxhuni, the repository owner. Every signing request is approved by hand.
  • Everyone with these roles uses multi-factor authentication for GitHub and SignPath.

Privacy policy

bloop has no accounts of its own, analytics or telemetry. Your settings and chat history are stored only on your computer. bloop connects to other systems only in these cases:

  • The model you choose. Your messages and recent chat history go to the provider you configured: a server you run (for example Ollama on 127.0.0.1), a server address you enter, or OpenAI's servers if you choose ChatGPT. Nothing is sent until you send a message, including clipboard text you attach to one.
  • ChatGPT sign-in. Only if you choose ChatGPT and sign in: bloop opens OpenAI's sign-in page in your browser and talks to auth.openai.com and api.openai.com to sign in, refresh the session and list your models.
  • Claude Code and Codex. If you choose one, bloop runs that program on your computer, and it contacts its own service under the account you signed in to.
  • Update checks. bloop asks GitHub (api.github.com) for the latest release 30 seconds after it starts and then every 6 hours, and downloads a new version from GitHub. No personal data is sent. You can turn this off under Settings › About.
  • Setup. During setup bloop checks for model servers on your own computer (127.0.0.1). This doesn't leave your computer.

Check a download

Each release lists a .sha256 file next to the installer. In PowerShell, Get-FileHash .\bloop-setup-<version>.exe should print the same value. Once releases are signed, Get-AuthenticodeSignature shows the signature too. On Linux, download the AppImage and its .sha256 file into one folder and run sha256sum -c bloop-<version>-x86_64.AppImage.sha256. Every version and its checksum is on the downloads page.
