# Bug audit — 2026-11-20

Line numbers refer to baseline `1425657`. The ranking puts loss of saved or unsaved data first, then crashes, stalls, and broken actions. These paths were identified by source inspection. Runtime evidence is recorded in `verification.md` as fixes are tested.

| Rank | Severity | Baseline source | Trigger and symptom |
| --- | --- | --- | --- |
| 1 | Breaking | `src/ui/jobs.rs:109`, `src/ui/jobs.rs:136`, `src/ui.rs:1277` | Failed chat saves discard the only queued snapshot. Switching chats can discard the in-memory copy before the save result arrives. A later successful save for a different chat clears the warning. |
| 2 | Breaking | `src/ui/chats.rs:183`, `src/ui/jobs.rs:77`, `src/ui/jobs.rs:153` | Deleting the active chat clears its in-memory turns and pending saves before SQLite confirms deletion. An I/O failure then leaves a stale or missing transcript and hides the saved row. |
| 3 | Breaking | `src/storage.rs:152`, `src/storage.rs:158`, `src/ui.rs:832` | One damaged conversation in the newest row or legacy history disables persistence for the whole app and sends an already-configured user back to setup. |
| 4 | Breaking | `src/storage.rs:172`, `src/storage.rs:180` | Legacy migration selects the current millisecond and uses the normal upsert. A chat already using that ID can be overwritten during migration. |
| 5 | Breaking | `src/config.rs:541`, `src/storage.rs:233`, `src/ui.rs:1251` | An oversized configuration can pass Settings validation, become live, and make every subsequent chat save fail. A long endpoint or unused provider field can exceed the serialized limit. |
| 6 | Breaking | `src/math.rs:364`, `src/math.rs:476`, `src/ui/rich.rs:235` | Deeply nested TeX can exhaust the stack during parsing. Replies are large enough to contain more nesting than the UI thread stack can handle. Rich-text worker owns this path. |
| 7 | Breaking | `src/cli.rs:771`, `src/cli.rs:787`, `src/cli.rs:808`, `src/cli.rs:861` | Windows continues when job creation or assignment fails. Cancel then only kills the immediate child. A surviving helper can hold inherited pipes open, leaving detached pipe tasks and occupying the app's capped blocking pool. |
| 8 | Breaking | `src/cli.rs:825`, `src/cli.rs:849` | The total CLI deadline wraps reads only. A blocked event consumer can hold the child and its pipes beyond the limit. |
| 9 | Breaking | `src/ui.rs:843`, `src/update.rs:429`, `src/update.rs:438` | Startup hashes cached installers on the GUI thread. A large cached file delays the first window, and a matching FIFO on Linux can prevent startup indefinitely. |
| 10 | Breaking | `src/chatgpt.rs:89`, `src/chatgpt.rs:356` | A successful token refresh that omits a replacement refresh token clears the saved token. Once the new access token expires, the user has to sign in again. |
| 11 | Breaking | `src/ui/jobs.rs:66`, `src/ui/chats.rs:210` | The save coalescer drops an older queued save even across an export of that chat. Export can then read a stale transcript or miss a new chat entirely. |
| 12 | Breaking | `src/ui.rs:1969`, `src/ui.rs:2006` | Cancel can collapse a busy peek. It drops the returned region update, so reduced motion can leave the invisible compact hit region intercepting desktop clicks. |
| 13 | Breaking | `src/main.rs:26`, `src/launch.rs:55` | A non-Unicode command-line argument panics before startup or single-instance signaling. |
| 14 | Breaking | `src/model.rs:43`, `src/ui/chats.rs:67`, `src/config.rs:611` | Extreme but valid SQLite IDs and timestamps or a maximum persisted profile ID overflow in debug builds. Chat/profile ID wraparound can also break creation in release builds. |
| 15 | Visual | `src/ui.rs:797`, `src/ui.rs:1033`, `src/ui.rs:2339` | Every streaming chunk and typewriter tick snaps history to the bottom. A user scrolling back to read an earlier turn is repeatedly pulled away. |
| 16 | Memory | `src/ui/chats.rs:90`, `src/ui/chats.rs:101`, `src/storage.rs:305` | Each search keystroke queues a full database scan. Generation IDs discard stale results after the scans have already allocated turns, excerpts, and result lists. |
| 17 | Minor | `src/presence.rs:103`, `src/presence.rs:217`, `src/ui.rs:731` | An expired peek deadline stays pending while a reply pins the peek. The 50 ms deadline subscription then keeps waking until the reply ends or is cancelled. |
| 18 | Minor | `src/update.rs:397` | Update cleanup matches the Windows installer prefix only. Old AppImage downloads and checksums accumulate on Linux. |

HTTP streaming already has bounded frames, an idle read timeout, a total request timeout, and a loopback cancellation test. The presence tests cover both a normal four-second peek and a cancelled busy peek. The latter exercises state transitions alone, which leaves the window-task bug above untested at baseline.
